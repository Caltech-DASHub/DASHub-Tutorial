# DASHub Tutorial

This repository includes some example code and documentation for how to work
with the data files on DAS Hub.

See the `read_and_plot_dashub_data_tutorial.ipynb` Jupyter Notebook for
example code, or the corresponding PDF if you cannot use the notebook.

Documentation of the various DAS Hub file formats is in [`file_formats.md`](file_formats.md).

If you have any questions or issues then please contact us via the
information provided on [the Caltech DASHub website](https://dashub.caltech.edu).
